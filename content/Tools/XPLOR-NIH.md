#nmr #mx #computational #software-dev

> [!info] Info
> Biomolecular structure determination package for NMR and other data sources. Based on the original XPLOR program ([[Axel T. Brunger]]) with extensive NMR-specific extensions. C++ framework with Python scripting interface. Co-developed by [[Charles Schwieters]] and [[Marius Clore]] at the NIH. Computational sibling of [[PHENIX]], both descending from the CNS/XPLOR lineage.

## Key Relationships
- [[Charles Schwieters]] -- principal developer (NIH CIT)
- [[Marius Clore]] -- co-developer (NIH NIDDK)
- [[Axel T. Brunger]] -- XPLOR / CNS ancestor lineage
- [[PHENIX]] -- computational sibling (shared CNS/XPLOR ancestry)
