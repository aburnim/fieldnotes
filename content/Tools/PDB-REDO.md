#mx #computational #validation

> [!info] Info
> Server and databank that re-refines, re-builds, and re-validates macromolecular structures from the [[wwPDB]] archive using modern methods. Led by [[Robbie P. Joosten]] in the [[Anastassis Perrakis]] group at the [[Netherlands Cancer Institute]]. Feeds improved models back into the wwPDB community and directly informs validation pipelines.

## Key Relationships
- [[Robbie P. Joosten]] -- lead developer
- [[Anastassis Perrakis]] -- group leader
- [[Netherlands Cancer Institute]] -- host
- Integrated with [[Coot]] and uses [[CCP4]] tools internally
- Glycan validation collaboration with [[Thomas Lütteke]]'s pdb-care lineage
- Central reference in [[wwPDB task force-X-Ray Validation|X-Ray Validation Task Force]] discussions
