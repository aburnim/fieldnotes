> [!info] Info
> SWISS-MODEL is a fully automated protein structure homology-modelling server and repository, developed at the [[Biozentrum]] / [[SIB Swiss Institute of Bioinformatics]], University of Basel, Switzerland. The SWISS-MODEL Repository (SMR) provides pre-computed models. ModelArchive (modelarchive.org) is a separate but related resource for archiving 3D models not suitable for PDB deposition (e.g., theoretical models). Both led by [[Torsten Schwede]].

## Key Relationships
- [[Torsten Schwede]] is already in your vault; he's also on the [[wwPDB task force-ModelCIF Working Group]]
- SWISS-MODEL is a data provider in [[3D-Beacons]] network
- ModelArchive designed for models not appropriate for PDB (e.g., integrative/hybrid models, homology models)
- SMR fetches AlphaFold and ModelArchive models via [[3D-Beacons]] Hub API
- [[Torsten Schwede]] is a co-author on the 2015 wwPDB IHM Task Force paper with [[Dr. Andrej Sali]], [[Helen M. Berman]], [[Thomas Ferrin]]

> [!faq] ModelCIF connection
> The [[wwPDB task force-ModelCIF Working Group]] is developing standards for archiving computational models. [[Torsten Schwede]] is a key player. This directly intersects with DiffUSE's interest in how predicted/modeled structures relate to experimental data.
